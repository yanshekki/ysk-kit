## 目標與使用者問題

DefinitelyTyped 要求 `@types/node` 的 major 必須對齊你實際運行的 Node major。kit 目前是 `engines.node` `>=24.0.0`、GitHub Actions `node-version: 24`、`@types/node` `^24.19.1`。Node **24 是 Active LTS**；Node **26 是 Current**（截至 2026-10-11 `lts=false`）。Vite 8 與 Expo 58 都不需要 Node 26。

Dependabot **#38** 只把 `@types/node` 推到 26.6.4，CI／engines 仍停在 24——形狀錯誤。該 PR **已經關閉**（2026-10-11，留言：偏好協調升級）。

結果：從最新 `origin/main` 開一條 PR，把 **engines、CI、types 一起** 移到 Node 26，用鎖步 **minor** 記錄平台故事（在 Vite 1.3.0 與 Expo 1.4.0 之後是 **v1.5.0**），等 CI 26/26，然後不合併。
