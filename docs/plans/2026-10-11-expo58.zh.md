## 考慮過的方案

| 方案 | 複雜度 | 分層 | 遷移 | 客戶端 | 備註 |

| C. 等到 `expo@latest` 是 58 且 RN 0.88 穩定 | 現在為零 | — | — | mobile 留在 SDK 57 | prompt 要求現在從 `next` 出 |

**選定：** A。  
**原因：** 使用者要的是協調的 SDK 58 升級，不是單套件 bump。Expo installer 是對齊工具。工作區 React 19.3 是 peer 所需。與 #41 獨立，CI 歸因才清楚。回滾是 pin Expo 57 + RN 0.86.3 + react 19.2.8。
